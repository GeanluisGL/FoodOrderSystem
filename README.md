## 🚀 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/GeanluisGL/FoodOrderSystem.git
   cd FoodOrderSystem
Configura la base de datos:

bash
# Crear base de datos
mysql -u root -p -e "CREATE DATABASE foodorder;"
Configura las variables de entorno en application.properties o .env:

properties
DB_URL=jdbc:mysql://localhost:3306/foodorder
DB_USER=root
DB_PASSWORD=tu_password
Instala las dependencias:

bash
# Maven
mvn install
# o npm
npm install
Ejecuta la aplicación:

bash
# Spring Boot
mvn spring-boot:run
# o Node
npm start
